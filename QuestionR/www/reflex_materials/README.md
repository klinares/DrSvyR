# Materials the reflexes draw on

The reflex files in `../reflexes/` were drafted from the materials below, from
graduate course notes on cognition and survey measurement (SURV632), and from
standard texts on survey error and the response process. Each reflex names its
own sources on its `Source:` line.

The PDFs are kept in this folder under short names, each with a markdown copy of its text (a
section per slide or page) that the Methodology page links to. `sources.csv` maps the name a
reflex's `Source:` line uses to the files and the citation. The PDFs are listed in this folder's
`.rscignore`, so they are not published with the app; the markdown files and `sources.csv` are.
