# Attitudinal scale

Version: 0.3

Task file for writing a set of attitude items intended to be combined into a
scale.

## Guidelines

<!--
In the words of the LLM Question Lab's informed prompt (Haensch, IASS/WSS
Session 3), from Yan, IASS/WSS Session 1, writing attitudinal questions.
-->

For attitudinal questions, also:

- Ask about a specific, clearly defined attitude object.
- Balance the question with a counter-argument.
- Use construct-specific response options, not agree–disagree.
- Use a filter or "no opinion" option for respondents without an opinion.

## Reflexes

### attitude_object
- **When:** Every attitude item.
- **Say:** Name one clearly bounded attitude object. If the object is broad, give a short definition before the question, in simple words, without making the question long.
- **Check:** Is the attitude object named and bounded so that respondents will have the same thing in mind?
- **Source:** Yan, IASS/WSS Session 1 (writing attitudinal questions 3)

### specific_before_vague
- **When:** Choosing what each item asks.
- **Say:** Prefer specific questions: they are less open to context effects and relate more closely to behaviour. If a general item is needed, place it before the specific items on the same topic and say so in the programming note.
- **Check:** If a general item is included, is it placed before the specific items on its topic?
- **Source:** Yan, IASS/WSS Session 1 (writing attitudinal questions 1 and 2); SURV632 Class 7 (assimilation and contrast)

### construct_specific_options
- **When:** Choosing the response format.
- **Say:** Ask about the construct directly with options in its own terms (how safe, how often, how much confidence) instead of a statement with agree-disagree options. Agree-disagree invites acquiescence and makes the respondent answer two questions at once.
- **Never:** Do not use agree-disagree for statements of fact, for statements with a quantity or comparison inside them, or for statements about the respondent's own experience.
- **Check:** Are the response options in the construct's own terms and not agree-disagree?
- **Source:** Yan, IASS/WSS Session 1 (writing attitudinal questions 8; agree-disagree exercise); SURV632 Class 8 and Class 11 (acquiescence as weak satisficing)

### balanced_stem
- **When:** Any item that poses a position.
- **Say:** Put both sides in the stem (favor or oppose; should or should not be allowed), or pose the item as a choice between two stated positions.
- **Check:** Does the stem state both poles or both positions?
- **Source:** Yan, IASS/WSS Session 1 (writing attitudinal questions 5); Fuchs, Haensch and Weber 2026 (balance of the request)

### direction_then_intensity
- **When:** A bipolar attitude asked by telephone or interviewer, or where a long scale would be read aloud.
- **Say:** Offer branching: first direction, then how strongly, with a follow-up lean question for those who choose neither. Put the main direction question in the item and the intensity and lean questions in its parts.
- **Source:** Yan, IASS/WSS Session 1 (writing attitudinal questions 6)

### non_attitudes
- **When:** The population may not have heard of the object or formed a view.
- **Say:** Add a filter question or a no-opinion option so respondents without an attitude are not pushed to invent one. Say in the notes that a strongly worded filter increases no-opinion answers.
- **Check:** Is there a route for respondents who have no knowledge of or opinion about the object?
- **Source:** Yan, IASS/WSS Session 1 (writing attitudinal questions 7); SURV632 Class 8 (don't-know filters)

### keying
- **When:** A set of items meant to form one scale.
- **Say:** Vary the direction of items so that a high score does not always mean choosing the same end, to expose acquiescence and straightlining. Write reverse-direction items as positive statements of the opposite pole.
- **Never:** Do not create a reverse item by adding "not" to another item.
- **Check:** Does the set include items keyed in both directions, without negations?
- **Source:** Yan, IASS/WSS Session 1 (writing attitudinal questions 8); SURV632 Class 8 (non-differentiation); Class 11 (satisficing)

### cover_the_construct
- **When:** A set of items meant to form one scale.
- **Say:** List the domains of the construct first, then write items so each domain is covered and no two items are rewordings of each other. Where the construct has cognitive, affective and behavioural components, say which each item taps.
- **Check:** Does each item tap a distinct stated domain, with no item a rewording of another?
- **Source:** Yan, IASS/WSS Session 1 (components of attitudes); Behzad et al. 2026 (structured coverage of beliefs, perceptions, behaviours); Martini, Scagnelli and Trujillo Medina 2026 (near-duplicate items)

### context_in_the_set
- **When:** Ordering the items and noting presentation.
- **Say:** Note in programming that item order within the set should be randomized or rotated where the mode allows, and that a grid should be avoided on small screens.
- **Source:** Yan, IASS/WSS Session 1 (writing attitudinal questions 4; context effects); SURV632 Class 7

### scale_is_a_draft
- **When:** The notes for any set of items meant to form a scale.
- **Say:** State that the set is an untested item pool. Before scores are used it needs a pilot with real respondents and checks of dimensionality and reliability, and subscales need more scrutiny than the total. For use in more than one country or language, comparability has to be tested, not assumed.
- **Never:** Do not predict reliability, factor structure or validity.
- **Source:** Martini, Scagnelli and Trujillo Medina 2026 (agreement strongest at whole-scale level, weaker for subscales); Behzad et al. 2026 (coarse structure recovered, finer structure diverges); SURV632 Class 12 (measurement invariance)

## Prohibitions

- Never present a set of items as an established or validated scale.
