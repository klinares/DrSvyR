# Mode

Version: 0.1

Modifier file. R keeps only the reflexes whose When names the mode chosen in
the form, plus any_mode and, when more than one mode is chosen, mixed_mode.

## Reflexes

### any_mode
- **When:** Any mode.
- **Say:** Write and appraise each item as it will reach the respondent in the stated mode: seen or heard, with or without an interviewer, on what size of screen.
- **Check:** Does the item work as written in the stated mode?
- **Source:** Yan, IASS/WSS Session 1 (mode-specific considerations)

### web
- **When:** Mode is web, self-administered on a computer.
- **Say:** Respondents read and can see all options: keep unordered lists short and note randomization because early options are favoured. Put definitions in the question text, not behind a click. Keep labels visible for every scale point and spacing even.
- **Never:** Do not rely on an interviewer to clarify, probe or record a volunteered don't know.
- **Check:** Is everything the respondent needs to answer on screen with the question?
- **Source:** Yan, IASS/WSS Session 1; SURV632 Class 8 (primacy in visual presentation; visual midpoint) and Class 10 (definitions are used only when effortless)

### mobile_web
- **When:** Mode is web on a mobile phone, or web where phones are likely.
- **Say:** Present items one by one, not in a grid. List options vertically. Keep stems and option labels short enough for a small screen. Avoid sliders, visual analog scales and date pickers; prefer an open number or a short vertical list.
- **Check:** Can the item be read and answered on a small screen without a grid, horizontal scale or slider?
- **Source:** Peytcheva and Yan 2025 as presented in Yan, IASS/WSS Session 1 (optimizing for mobile web)

### telephone
- **When:** Mode is telephone or any interviewer-read mode without show cards.
- **Say:** The respondent hears the item once. Keep stems short, put the response options at the end of the stem or use branching, limit the number of options read aloud, and write the item to be read exactly as worded. Later options are favoured when heard. Add interviewer instructions for what is read and what is not.
- **Never:** Do not use long lists, grids or scales with many labelled points to be read aloud.
- **Check:** Can a respondent hold the question and all its options in mind after hearing them once?
- **Source:** Yan, IASS/WSS Session 1 (multimode considerations 5 and 6); SURV632 Class 8 (recency in spoken presentation; working memory)

### face_to_face
- **When:** Mode is face-to-face with an interviewer.
- **Say:** Note where a show card is needed, what the interviewer reads and does not read, and how a volunteered don't know or refusal is recorded. Flag items where an interviewer's presence invites edited answers and suggest the respondent enters those answers privately.
- **Check:** Are interviewer instructions and any show card specified, and are sensitive items protected from the interviewer and bystanders?
- **Source:** Yan, IASS/WSS Session 1 (sensitive questions 1 and 2); SURV632 Class 10

### paper
- **When:** Mode is paper, self-administered.
- **Say:** Keep routing simple and visible, since nothing enforces a skip. Avoid filters with long branches. Give written instructions for how to mark answers and for open numbers.
- **Check:** Can the respondent follow the routing without help?
- **Source:** Yan, IASS/WSS Session 1 (paper surveys; visual design)

### mixed_mode
- **When:** More than one mode is used, or the mode may change later.
- **Say:** Use the same wording, format and option order in every mode, built to the limits of the most restrictive mode, usually telephone. Say whether the goal is comparison across groups or modes, which calls for identical stimuli, or the best overall estimate, which allows each mode its best form. Say that some mode differences will remain.
- **Never:** Do not write a format that exists in only one of the modes.
- **Check:** Would the item be asked in the same words and format in every mode used?
- **Source:** Peytcheva and Yan 2025 and Tourangeau 2017 as presented in Yan, IASS/WSS Session 1 (multimode considerations 1 to 8)

## Prohibitions

- Never assume a mode the brief does not state; ask for it.
