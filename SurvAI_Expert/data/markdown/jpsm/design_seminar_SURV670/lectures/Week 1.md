# Tasks and Assignments

---

* Submit tasks and assignments through the Canvas site (format: <u>MS Word</u> document, PowerPoint presentation where applicable)
* Seven group and one individual assignment (often due Mondays, 5 pm). Each team member will receive the same grade for each assignment
* Homework submissions will be graded on four-levels: check-plus (100), check (90), check-minus (80), and not submitted (0)
* If homework is submitted late without prior permission, scores will be check-plus (70), check (60), and check-minus (50)
* Grading:

| Description | % |
| :--- | :--- |
| Seven assignments | 20 |
| Preliminary presentation | 10 |
| Final presentation | 20 |
| RFP Proposal | 50 |
| Total | 100 |

* Peer (teammate) evaluations - based on the significance of each individual’s contributions - will be used to adjust the Team grade contribution to the individual grade.
