# Class Structure

We will be using a **flipped classroom structure**. In this course, you are responsible for **watching video recorded lectures and going through the readings,** and then attending class meetings where students have the chance to discuss the materials from a unit with the instructor. In general, the class time will be used for **discussion based on the forum posts, answer questions** as well as walking through **R code examples.**

# Flipped Classroom Design

**Before class:**

* Watch the online video lectures.
* Do the readings.
* Post in the Discussion Forum for the week.

**During class:**

* Ask questions based on forum post discussion topics.
* Work through the R coding examples.

**After class:**

* Work on homework assignments.
* Set up an office hours appointment to clarify any remaining questions you might have.

# Forum Posts

You must submit a **forum post every week** relating to the content covered in that week. You should post any questions you might have had about the content, including any R material that you may have struggled with. If you have no questions about the material, you can post comments about what you want to learn, or respond to another student.

We will use the questions to inform the first part of the discussion during class.
